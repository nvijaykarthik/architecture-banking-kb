# 2-Week Mastery Plan — Custody & Asset Management

> 14 days, 2 hours/day = 28 hours total.
> 1. Open the brief (5–10 min). 2. Read the detail (20–35 min). 3. Do the practice (10–15 min). 4. Self-quiz before bed.
>
> **Golden rule:** Cover C1 + 6–8 core C2 topics before anything else. C3–C10 is second wave.

## Guardrails

| Do | Do not |
|----|--------|
| Write one afternoon-practice entry per day (reconcile, map, or ADR draft) | Cram multiple topics in one sitting |
| Review Friday, then Sunday of each week (spaced repetition) | Skip the detail and read only the brief |
| Log one question you cannot answer on a "red-flag" list | Pretend you know a term |
| Use Mermaid for every mental model; hand-draw before typing | Use bullet-list-only explanations |

## What "ready" looks like

By Day 14 you should be able to:
1. Define custody, AUM, wealth management, and investment banking in 2 minutes each.
2. Name 8 asset classes and the safekeeping mode for each.
3. Describe the custody value chain end-to-end with one diagram.
4. Explain segregated vs omnibus vs nominee accounts in a loan-officer meeting.
5. Describe DVP and one settlement window in plain language.
6. Cite one regulation per major jurisdiction (US, EU, UK, Asia) and its core requirement on the custodian.
7. Describe the three main risk categories for custody and one control per category.
8. Draw the reference architecture (custodian → CSD/CCP → client) and say what each layer does.
