# Custody & Asset Management Documentation

Bank operations knowledge base for custody and asset management.

## What is here

- `templates/` — Brief and detail templates (must be used for every topic)
- `tasks/` — pending and covered topics

## How to use

1. Pick a topic from `TASKS.md`.
2. Read the corresponding templates in `templates/`.
3. Produce `briefs/{{slug}}.md` and `details/{{slug}}.md`.
4. Each must contain at least one Mermaid diagram.
5. Mark the topic `✅` in `TASKS.md` only after both files exist.

## Rules

- Brief: ≤ 2000 words, interview-ready, 5–10 min read.
- Detail: ≤ 4000 words, 13 sections, ≥1 Mermaid diagram.
- No emojis.
- Tone: direct, terse, developer-to-reader, no fluff.
